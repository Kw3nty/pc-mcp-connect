# PC MCP Relay

Сервер-посредник для **PC MCP Connect**. Даёт MCP-серверу на домашнем компьютере постоянный HTTPS-адрес для Notion — без ngrok, Cloudflare, белого IP и проброса портов.

```
Notion ──HTTPS──▶ этот сервер ◀──WebSocket── PC MCP Connect на компьютере
```

Компьютер сам подключается к серверу исходящим соединением. Ссылка для Notion не меняется: `https://<сервер>/<канал>/<токен>/mcp`.

## Развернуть на Hugging Face (бесплатно, открывается из России без VPN)

1. Зарегистрируйся на https://huggingface.co.
2. **New → Space** → SDK: **Gradio** → шаблон *Blank* → Hardware: *CPU basic · 2 vCPU · 16 GB · FREE* → видимость **Public** (иначе Notion не достучится). Docker-Spaces теперь платные, а Gradio — бесплатный; сам Gradio релею не нужен, Hugging Face просто запускает `app.py`.
3. Загрузи в Space три файла из этой папки: `app.py`, `relay.py`, `requirements.txt` (*Files → Add file → Upload files*, с заменой существующих). Файл `README.md` Space'а **не трогай** — в нём настройки, которые Hugging Face создал сам.
4. Подожди сборку (1–3 минуты, статус *Running*).
5. Адрес сервера — `https://<твой-логин>-<имя-space>.hf.space`. Проверка: `https://<адрес>/_relay/ping` должен ответить `ok`.

Если уже есть чужой Space с релеем — достаточно нажать **⋮ → Duplicate this Space**.

### Личный или общий сервер

- **Общий** (по умолчанию): подключиться может любой PC MCP Connect, каждый компьютер — в свой канал. Подходит, чтобы один раз развернуть сервер для всех пользователей.
- **Личный**: в *Settings → Variables and secrets → New secret* добавь `RELAY_SECRET` (длинная случайная строка). Тогда подключатся только компьютеры, у которых в настройках PC MCP Connect указан этот же секрет.

Другие переменные: `REQUEST_TIMEOUT` (секунд, по умолчанию 300), `MAX_CHANNELS` (по умолчанию 500).

## Важно знать

- Бесплатный Space засыпает после ~48 часов **без входящих запросов**. Пока PC MCP Connect на связи, он раз в несколько минут сам пингует сервер, так что обычно сервер не засыпает. Если всё же уснул — открой страницу Space и нажми *Restart*.
- Сервер не хранит ни токены, ни данные: только пересылает запросы. Токен в ссылке проверяет MCP-сервер на компьютере. Но технически владелец сервера видит проходящий трафик — для полной приватности сделай личный сервер.

## Свой VPS / локально

```
pip install -r requirements.txt
PORT=8080 RELAY_SECRET=... python relay.py
```

или Docker: `docker build -t pcmcp-relay . && docker run -p 8080:7860 pcmcp-relay`. Перед сервером нужен HTTPS (Caddy / nginx) — Notion подключается только по HTTPS.
